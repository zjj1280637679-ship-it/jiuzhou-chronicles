# API 来源与独立适配

2026-10-20：站长共享 API 是一个来源，不是其他 API 的准入条件。

此前代码用“共享健康就绪或有个人 Key”判断能否联网，再把“Key 为空”解释成选择共享服务。这使无 Key 代理不能独立使用，自定义端点也可能被静默忽略。设置测试同样受影响，切换端点后还可能显示旧来源的成功及缓存。

## 当前行为

| 项目 | 站长共享 API | 自定义 API |
| --- | --- | --- |
| 选择 | 明确选择 shared | 明确选择 custom |
| 端点 | 公开游戏 Worker | 用户填写的完整 Chat Completions URL |
| 认证 | 服务端 Secret，不附个人 Key | Key 非空才加 Authorization，可留空 |
| 模型 | 共享服务配置 | 保留用户模型，不擅自替换 |
| 共享健康检查 | 只展示服务状态 | 不作为可用条件，不改变选择 |
| 请求失败 | 明确失败并保留本地玩法 | 同左，不自动转去共享额度 |

远端/离线开关与来源独立。已有关闭偏好保留，首次使用默认共享。旧配置有个人 Key 或非默认端点时迁移为自定义；已有明确来源不被覆盖。用户清空自定义端点或模型时明确报错，不偷偷补回 DeepSeek。

故事、弥合和测试共用 `harness/providers.js`。测试使用点击时的未保存表单，不保存设置或推进剧情；表单改变后旧结果过期。

## 插件与请求

`normalizeConfig` 迁移设置；`resolve` 捕获路由；`createRequest` 构造请求。共享和自定义通过 `register({id,resolve,request})` 独立注册，返回的清理函数可移除插件。同ID替换后旧快照明确失效，不静默调用新实现。

来源identity是本会话比较标记，不含明文Key，也不是认证凭据。保存来源/端点/模型/凭据变化时取消旧请求并更新版本；旧回复、进度和指标不能提交到新来源。供应商无关的玩家剧情历史继续保留。

自定义支持通用Chat Completions与DeepSeek适配。通用请求不附DeepSeek thinking/reasoning_effort或共享mode字段，保留原生工具调用ID及结果。输出参数可选max_tokens/max_completion_tokens，留空不发送，不把DeepSeek的范围当作所有来源的上限。不同协议需要相应适配，不能声称任意网址都兼容。

共享的服务端模型标签是异步状态信息，不是客户端可配置模型；它不改变来源identity，以免健康检查打断合法生成。最近一次生成记录该次响应实际模型。缓存使用DeepSeek hit/miss或标准cached_tokens，缺少有效分母时显示“未提供”，不伪造0%或100%。

## 验证

92个Node回归、Chromium手机模拟通过，包含无Key端点、真实Worker工具循环、来源切换/迟到回复、并发健康检查、表单快照及未知缓存。模型响应为测试数据，不代表用户第三方账户已经认证。公开页面发布和共享短请求另行验收；此前5000正文字符实测不冒充本次第三方接口实测。
