## 运行方式

- 游戏是静态网页，默认浏览器本地剧情。`npm start` 在 8088 端口提供公开静态文件；`npm run build` 生成仅含公开资源的 `dist/`，Vercel 使用该目录。
- 在线 AI 由玩家显式选择个人 API 来源：DeepSeek、Google Gemini 或自定义／本机兼容接口。Key 是否非空不用于推断来源；无 Key 的兼容服务也可以独立使用。
- 不依赖站长共享后台、共享健康检查或自动共享回退，不需要注册腾讯云或部署 Cloudflare Worker。
- 清理已删除根目录代理 API、自动寻找本机密钥的服务逻辑及 `pure-local/` 重复副本。旧来源配置仅保留迁移逻辑；真实本机配置不再读取，旧存档与插画 ID 兼容继续保留。
- `harness/` 中的 Worker 指浏览器 Web Worker 插件，承担本轮世界读取、草稿与插画工具执行，与 Cloudflare 后端无关。
- 设置、连接测试、请求适配和 Google 真实样本边界见 [API 来源](API-SOURCES.md)。

## 已确定的交互规则

- 抉择是特定时机出现的模态弹窗，不占普通阅读布局。
- `set_scene_background` 控制持续舞台背景；`select_illustration`／兼容 `show_illustration` 控制独立图片弹窗。背景不触发弹窗，弹窗不改背景，关闭图片不跳页。两种工具的草稿、清除和交付分开处理，见 [插画说明](ILLUSTRATIONS.md#ai-选图)。
- 篇幅仍为 500／2000／5000 档，提示词分别要求 1000／2500／5500 字正文。程序不核算字数，不设正文不足错误，不按差额强制续写，也不因短文拒交。
- 游戏和设置不显示运行日志或诊断指标；保留简单等待、取消、连接测试结果和必要可恢复错误。
- 请求失败或取消保留原行动与原判定结果，由玩家决定重试、本地继续或放弃；程序不自动发起收费重试。
- 进度备份不含 API 配置。存档失败不伪装成功，不静默删减正文；恢复失败不替换当前世界。
- 不依据旧方案重新加入邀请码、真人验证、站长开关、项目频率或额外输出配额。
