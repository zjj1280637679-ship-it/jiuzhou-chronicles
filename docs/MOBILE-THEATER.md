# 掌上剧场 · 手机 UI

当前手机界面沿用项目方选定的第二版阅读布局。对应历史截图与当时回归见 [设计验收档案](history/MOBILE-DESIGN-QA.md)，不代表本次清理重新执行了实体手机验证。

- 竖屏上方是场景画面，下方为独立滚动正文，底部保留上一段、继续阅读与真实段落位置。触碰舞台、选字和正文滚动不推进剧情。
- 抉择只在剧情触发时作为模态弹窗出现；平时不显示、不占位。自拟行动位于抉择弹窗，返回阅读不结算行动。
- 自拟行动的提交、取消位于固定底栏，内容和输入区独立滚动。输入视口适配只约束当前弹窗，关闭或失焦后清理。
- 更多菜单收纳资料、收藏、恢复和设置。设置使用折叠分组及固定测试／保存底栏。
- 图片互动在覆盖舞台的独立居中弹窗中展示，正文不嵌入大图卡。关闭图片不跳页、不改背景；说明内容独立滚动，坏图可关闭后继续阅读。
- 生成期间只显示简单等待与取消，不显示模型调用、工具次数、耗时、Token、缓存或其他运行日志。
- 触屏横屏可左右分栏；同页面切换桌面与手机时恢复 DOM 位置。字号调整仅本页面有效。

背景图、纹样和图标使用本地资源；图标来源与许可证见 `data/mobile/icons/`。旧图柄保留兼容，不以移除旧版界面为由删除存档和收藏引用的素材。

## 验证入口

```powershell
node test-mobile-layout.mjs
node test-input-viewport-browser.mjs
node test-illustrations-browser.mjs
node test-background-tools-browser.mjs
node test-exploration-ui.mjs
```

这些脚本验证浏览器中的视口、弹窗、导航与恢复。缩小浏览器视口只近似键盘占用；真实 iOS Safari、Android 输入法与物理安全区需要实机验证。真实模型连接与布局回归也需分别报告。
