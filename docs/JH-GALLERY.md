## 调用

```js
search_illustrations({query: "渡口 核名"})
show_illustration({token: "后金·渡口核名"})
show_illustration({token: "后金·渡口核名·兜裆布"})
set_scene_background({token: "背景·后金河岸渡口·常态"})
```

查询只读取文字，不取图片；AI选图先暂存，成功交付后才实际显示并取图。手动画库只有点击“展卷预览”才请求该图。未被使用的图片不会批量下载。

网页资源保留原尺寸，WebP quality=87 / method=6 编码，没有裁切、缩放或改变构图。PNG原图另行备份，不放入网页首屏。

正式身份仍由 `catalog.json` 管理：`sourceId` 对应原制作编号，`familyId` 分组，`parentId` 指向直接母图或原版，`backgroundId` 指向无人母图。`originalSha256` 与 `webSha256` 分别记录原PNG和网页WebP内容。分类与文字检索不需要这些原PNG。

衣装只说明可见服饰，不自动设定俘虏、奴役、罪名、效忠或胜负；未修改旧静态剧情的默认背景和旧句柄。
