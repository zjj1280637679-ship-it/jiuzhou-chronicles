# 掌上剧场 · 手机 UI

2026-10-23 更新：运行日志、模型/工具次数、耗时、Token、缓存及诊断面板已从 UI 移除，仅保留推演中、取消和必要错误。图片弹窗与抽屉分开，覆盖全视口居中显示，正文不再嵌大图卡。背景工具只控制舞台，弹窗工具只控制独立图片窗口；静态配图不隐式弹窗，弹窗关闭不跳页或改背景。旧版进度显示和内联图卡描述仅供历史参考。

2026-10-20，构建2026.10.20.0700。采用项目方选定的第二版正常阅读图，整体替换原 mobile.css 与 mobile-ui.js，继续使用现有剧情、设置表单和自动存档。

- 竖屏上方场景画面、下方独立滚动正文，底部明确上一段/下一段和真实段落数。正文滑动、选字或触碰舞台不推进剧情。
- 抉择只在剧情触发时作为模态弹窗出现；平时不显示、不占位。自拟行动属于抉择弹窗。返回阅读沿用原上一段逻辑，不结算行动。
- 自拟行动的提交/取消固定在面板底部，内容和输入区独立滚动；短屏与键盘占用高度时也能完整操作。
- 更多面板保留全部原功能，篇幅与字号放在阅读设置；AI生成进度和取消位于阅读区。抽屉固定标题、内容滚动，并支持焦点返回、键盘与背景隔离。
- 手机判定使用统一宽度断点；触屏横屏左右分栏，同一页面切回桌面时还原原DOM位置。字号仅本次页面有效，不新增存储或读取个人Key。
- 续玩时同步刷新导航，修复已恢复正文但上一段仍禁用的问题。

新增画面与纹样为独立生成的本地WebP资源（合计约227KiB），未将效果图裁成UI。图标来自本地打包的Phosphor Light，来源和MIT许可证见 `data/mobile/icons/`。其他阵营沿用现有阵营画卷；正文套图仍可独立打开、滚动说明和关闭。

验证：95个Node测试、四阵营回归、原390×844浏览器AI/真实WebWorker模拟全部通过。新增 `test-mobile-layout.mjs` 覆盖320×740、390×844、430×932、844×390和1440×900，以及同会话跨断点、字号、页码、抉择返回、自拟取消/提交、取消生成、设置、插画与存档续玩。模型均为拦截模拟，没有付费调用。

已用内置浏览器核对390×844真实本地页面。视觉对比见根目录 `design-qa.md`。浏览器缩小视口只能近似键盘占用；实际iOS Safari、Android输入法和物理安全区尚未实机验证。
