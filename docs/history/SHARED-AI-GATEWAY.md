## 验证和失败显示（代码行为与测试边界）

设置区区分网关就绪、实际生成和本地回退；“重新检查连接”只读取健康状态，不调用模型。AI 回复格式无效、上游认证或网络失败时显示原因；不把本地文本标成真实模型输出。

“秘钥”设置的“测试请求”会用当前未保存的表单发起一条真实短请求：Key 留空测试共享 Worker，填写 Key 测试表单中的私有端点和模型。共享模型由服务器配置，结果显示实际返回的模型、通道与耗时。测试无需先保存或开启远端偏好；不会修改存档、剧情队列、历史、缓存指标或真实生成状态。表单修改后需重新测试，测试通过后需保存才能应用。

测试使用固定虚拟对白与 `suture` 格式，最多 256 输出 Token，45 秒结束未完成的测试且不自动重试；这只适用于诊断请求，不限制正常剧情生成。只有返回含非空对白的有效 JSON 才算成功。HTTP 认证、额度、频率及格式/网络错误只显示固定原因，不展示原始上游正文或密钥。

设置区新增真实剧情指标：不含空白的正文字符数/中文数、有效段数、模型选项数与补齐后界面选项数、耗时、完成Token、结束原因和篇幅符合情况。插画说明与思考内容不计入正文；`finish_reason` 缺失时显示未知，`length` 明确标为输出未完成，不把半截回复算完整成功。

生成期间顶部提供“取消本次生成”，取消等待后回到可继续的本地剧情，不自动重发；共享生成仍无自动截止时间。浏览器取消并不能保证模型服务停止计算或计费。正常网络拒绝、无效正文、截断回复和主动取消都不能写入半轮AI历史；坏的可选选项/特效被忽略或补齐，不丢有效正文。
