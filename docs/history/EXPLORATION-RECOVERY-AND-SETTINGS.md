保留已选定的掌上剧场布局和现有 Worker 工具循环。借用旧小游戏的交互目标，重新实现恢复与展示模块；没有复制旧 HTML、预置凭据、搜索适配栈或自动生图流程。

## 玩家可见变化

- **设置**：单一表单分为连接来源、生成偏好、连接测试、进度与备份。兼容参数、输出参数、指标诊断默认折叠；测试和保存 AI 设置固定在底栏。缓存入口自动展开诊断。自定义、站长共享、本地模式仍独立，空 Key 不会切换来源。
- **失败恢复**：自由探索报错或取消后，保留原行动与原骰点，回到此前已完成的世界状态。玩家可以按原行动重试、明确改用本地剧情，或放弃尝试。没有自动收费重试。恢复卡可以收起，从更多菜单重新打开。刷新后保留待处理行动，不自动发请求。
- **进度**：存档写入失败显示可见提示，保留上次成功存档，不悄悄裁掉正文。可重试保存；进度备份独立导出、选文件预览、明确恢复，不导出或覆盖 API 配置。恢复文件写入失败不会替换当前世界。
- **收藏**：从更多菜单收藏当前已交付段落，保存文字和对应本地画卷引用。支持回看、复制、取消收藏；同段落去重，生成或修订后的不同场景分别标识。收藏失败不会影响游戏。
- **输入**：独立 VisualViewport 适配器在检测到输入和明显可见高度变化时约束当前弹窗，保留可见的提交、取消和收起区。地址栏变化、桌面和用户缩放不启用适配。关闭或失焦后还原。
- **叙事**：稳定系统规则与草稿工具说明要求下一步行动只放在 `choices`，正文呈现已发生的行动与眼前悬念。提示词属于生成约束，不能保证所有服务每次都完全遵守；没有用关键词删改玩家交付正文。
- **选项连续性**：打开抉择不再消耗模型已交付的选择；返回阅读、续玩、失败后放弃仍显示同一组。命运之结保存对应选择，回溯恢复当时的选择；旧结点和离开场景时清除未来选择。
- **指标与星盘**：选择指标计入3项建议加1项自拟行动；人物星盘明确为内置设计参考分布，不冒充实时玩家采样。

## 模块边界

| 模块 | 职责 |
| --- | --- |
| `game-recovery.js` | 游戏进度白名单、事务快照、行动标识和原骰点、存档及备份格式 |
| `recovery-ui.js/css` | 恢复卡、保存状态、备份预览与明确恢复入口 |
| `scene-favorites.js` | 场景身份与收藏存储，只收玩家可见字段 |
| `favorites-ui.js/css` | 可选只读收藏抽屉，不调用模型、不推进世界 |
| `settings-ui.js/css` | 原设置表单的折叠、底栏与结果定位，不承担 API 路由 |
| `input-viewport.js/css` | 当前输入弹窗的临时视口适配，支持卸载清理 |

生成仍由既有隔离 Worker 插件处理；正文仍只核算最终交付的 `beats[].text` 非空白 Unicode 字符，汉字另列。收藏、备份、工具、思考、JSON 和选项不进入正文指标。新增 UI 模块不进入模型稳定请求前缀，也不默认增加收费链路。

逐段视觉状态同步仍是后续可选项；本次没有引入新剧情协议、全局主题工具或另一套引擎。
