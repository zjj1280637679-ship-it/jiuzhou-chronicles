# 后金前三幕：10张人物动作GIF

用户确认接受低帧率人物动作样片后扩展本批。覆盖第一幕、第二幕全部三个分支、第三幕每线两个分支，共10个场景，不代表覆盖全部后金剧情。精确映射、动作、体积、SHA256见 QING-ACTION-GIF-MANIFEST.json。

## 制作与边界
剧情依据 data/qing-363-tree.json 与对应原插图。imagegen 制作12格连续人物姿态图集，编码为3秒、12帧、4fps、836×470、128色无抖色GIF。真实存在人物姿态变化，但属于有限帧动作插图，不称流畅视频、真人实拍或零漂移。源格约482×270级别放大，可能有纹理跳动、首尾接缝及量化色阶。仍有空间优化，不应宣传为电影质量。

固定全局调色减少体积，不牺牲输出尺寸作为唯一压缩手段。每张约2.6–3.5MB；移动炮阵裁切保留炮手动作，但炮口和指挥者靠边，这是已知构图限制。

## 加载与兼容
手机/桌面共用 pathFor/posterFor；首帧PNG从对应最终GIF逐像素解码。仅下载当前场景首帧与GIF；GIF解码成功切动画；失败或减少动态保留同一首帧，不替换旧场景图。其他节点和原资产/存档句柄不变。旧WebP、npc-v2、photoreal-v1均保留用于显式回滚。

## 验收
独立资产审查按用户已接受的4fps边界核查动作、NPC、手机中心裁切、循环、时长及首帧匹配；自动像素证据见GIF-FIRST-FRAME-EVIDENCE.json。浏览器专项动态遍历全部映射，在390/1440两宽度检查首帧与动画解码、当前资源范围并截图。这是节点投影，不声称逐条点完全部剧情或实体iPhone测试。发布后CI结果另行确认。
